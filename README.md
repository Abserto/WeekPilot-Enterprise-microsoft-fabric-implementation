# Enterprise Microsoft Fabric Implementation

This repository contains a starter structure for the Enterprise Microsoft Fabric implementation project.

## Repository layout
- `docs/` for architecture, governance, and onboarding
- `data/` for bronze, silver, and gold layers
- `notebooks/` for ingestion, transformation, and validation notebooks
- `semantic-models/` for analytics assets
- `reports/` for Power BI deliverables
- `pipelines/` for deployment automation
- `scripts/` for SQL and Python helper scripts
- `tests/` for validation assets
